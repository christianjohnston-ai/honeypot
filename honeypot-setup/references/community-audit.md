Cross-check anchors:

- [OpenCanary logger constants at v0.9.10](https://github.com/thinkst/opencanary/blob/fb12e4fefbdb1b9acd1e5561a2614f827ab639ff/opencanary/logger.py): FTP login 2000, HTTP GET 3000, HTTP login 3001, SSH connection 4000/login 4002, SMB open 5000, port SYN 5001, Telnet login 6001, HTTP proxy login 7001, MySQL login 8001, RDP 14001. [Samba module](https://github.com/thinkst/opencanary/blob/fb12e4fefbdb1b9acd1e5561a2614f827ab639ff/opencanary/modules/samba.py) consumes Samba audit logs; it does not create file shares from a `smb.filelist` JSON field.
- [Canarytokens deprecation notice](https://github.com/thinkst/canarytokens/blob/61f3e0c7790f08f1be09a947cb0d68e6152cde6a/README.md#deprecations), [frontend routes](https://github.com/thinkst/canarytokens/blob/61f3e0c7790f08f1be09a947cb0d68e6152cde6a/frontend/app.py), [AWS response model](https://github.com/thinkst/canarytokens/blob/61f3e0c7790f08f1be09a947cb0d68e6152cde6a/canarytokens/models/aws_keys.py).
- [Official free-service getting started](https://docs.canarytokens.org/guide/getting-started) versus [commercial Console API](https://docs.canary.tools/canarytokens/actions.html): different products, credentials and type names. Do not substitute endpoints or infer hosted free API stability from the commercial manual.

No claim is made that the entire community repository is unsafe. These findings concern these inspected paths/revisions and explain why their instructions were evaluated as research inputs instead of executed or copied.
